# Quest1 Projects

This repository contains multiple applications developed during the Quest1 internship.

## Repository Structure

```
Quest1_Projects/
├── food-ordering/
├── observability/
├── docs/
```

## Applications

### Food Ordering

A rule-based multi-agent food ordering application.

Main components:
- Restaurant Recommendation Agent
- Order Management Agent
- Payment Verification Agent
- Delivery Tracking Agent

Run:

```bash
cd food-ordering
python main.py
```

---

### Observability

A multi-agent workflow observability platform.

Main components:
- Planner Agent
- Research Agent
- Code Generator Agent
- Reviewer Agent
- Test Agent

Features:
- Shared workflow context
- Retry mechanism
- Error handling
- Logging

Run:

```bash
cd observability
python main.py
```
